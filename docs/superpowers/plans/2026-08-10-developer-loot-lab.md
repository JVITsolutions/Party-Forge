# Developer Loot Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the developer-only Party Forge Loot Lab with deterministic responsive batches up to 100,000 attempts, a three-pane Workbench, a dedicated Analysis view, exact-sequence drilldown, isolated sandbox issuance, exports, and complete keyboard/controller support.

**Architecture:** Pure typed GDScript services own frozen batch specifications, shared eligibility, incremental aggregation, reachability, exports, jobs, and session state. A dedicated Loot Lab scene presents those services inside the existing Developer Item Sandbox; generated previews remain session-only until an explicit schema-2 sandbox transaction reissues one into the isolated developer owner. The production generator remains the sole item-generation implementation, and existing balance evidence consumes the same eligibility/opportunity analysis to prevent semantic drift.

**Tech Stack:** Godot 4.7.1 stable Mono, typed GDScript, Godot `Control` scenes, JSON-safe deterministic documents, `AtomicJsonStore`, existing item-generation/ownership/presentation services, PowerShell, Git worktrees, and custom headless unit/integration runners.

- [ ] **Step 3: Implement bounded advancement and production-safe injection**

Default the Callable to `ItemGenerationService.generate`. A zero time budget disables clock checks for exact-count tests; positive budgets check `Time.get_ticks_usec()` between attempts.

```gdscript
func advance(max_attempts: int, time_budget_usec: int) -> int:
	if not is_active() or max_attempts <= 0:
		return 0
	var started_usec := Time.get_ticks_usec()
	var advanced := 0
	while advanced < max_attempts and _attempted < _spec.target_count:
		if _cancel_requested:
			break
		if time_budget_usec > 0 and advanced > 0 and Time.get_ticks_usec() - started_usec >= time_budget_usec:
			break
		_generate_next()
		advanced += 1
	_finalize_if_terminal()
	return advanced
```
