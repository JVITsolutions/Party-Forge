# Sunweld Bastion Godot Integration and Pilot Validation Plan

> **Execution note:** Import only Blender revisions explicitly approved under the asset-production plan. Keep gameplay IDs and data unchanged.

**Goal:** Integrate the approved bodies and eleven Sunweld Bastion masters behind stable Godot wrappers, derive both icon sizes from the masters, and pass technical, visual, gameplay-camera, and full regression gates.

**Architecture:** Reviewed GLBs are immutable inputs. Existing `.tscn` roots and `.tres` IDs remain stable adapters. The tested pivot-to-bone driver animates the canonical rig, rigid items use semantic sockets, and shared-skinned meshes rebind to that one rig. Imported multi-surface materials and stable body regions participate in transactional equipment state. Scene-based icon and pilot-QA renderers stage review outputs before tracked promotion. Manifest validation binds each promoted file to its exact approved source.

**Tech stack:** Godot 4.7.1, GLTF/GLB, typed GDScript, SubViewport rendering, PNG, JSON/SHA-256, existing Party Forge tests.
